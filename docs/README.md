# PatientCapital

PatientCapital помогает владельцу долгосрочного портфеля ответить на конкретный вопрос: «как
распределить новое пополнение с учётом моих целей, уже купленных активов, доступных цен, лотов и
комиссий?». Проверяемый результат MVP — локальный Docker-запуск, в котором пользователь ведёт
профиль и операции, видит аналитику и получает объяснимый, арифметически воспроизводимый черновик
покупок без автоматического исполнения у брокера.

## Акторы и сценарии

- **Владелец портфеля** задаёт инвестиционный горизонт, целевое распределение и денежное
  пополнение; сравнивает план с доступным бюджетом и вручную подтверждает фактические покупки.
- **Codex-агент** по запросу пользователя читает тот же проверенный portfolio snapshot и вызывает
  узкие read/propose tools; он не владеет формулой распределения и не исполняет сделки.
- **Оператор** запускает Docker-контур, управляет секретами и проверяет health/eval результаты.
- **GigaChat** является только экспериментальным внешним provider: до live-gate он выключен, после
  допуска может объяснять уже рассчитанный план или извлекать намерение в строгую схему.

## Границы

В MVP входят один локальный пользователь, профиль брокера и комиссий, справочник вручную заданных
активов/цен/лотов, целевые доли, журнал операций, расчёт позиций и отклонений, план распределения
нового взноса, аналитическая панель, журнал recommendation run и agent-facing инструменты.

Не входят исполнение поручений, подключение к брокерскому кабинету, custody денежных средств,
прогноз доходности, рыночные котировки в реальном времени, налоговая оптимизация, деривативы,
маржинальная торговля, несколько пользователей и публичный SaaS. Публичное или коммерческое
предоставление персонализированных рекомендаций блокируется до отдельного юридического заключения
по статусу инвестиционного советника и требованиям к robo-adviser ПО.
